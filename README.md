# Advanced Corporate Site

CODEJUMP 上級編の「固定サイドメニュー（ハウスメーカー）」課題として制作しているWebサイトです。

## 概要

HTML・CSS・jQueryを使用して、ハウスメーカーをテーマとしたコーポレートサイトを制作しています。

CODEJUMPの課題を通して、固定サイドメニューのレイアウト設計、動画背景の組み込み、CSSによる演出やフロー図作成、jQueryを使ったスクロールイベント制御について学習しています。

## 学習内容

- HTMLによるWebサイトの構造設計
- PC時の固定サイドメニューとレスポンシブ（スマホ時ハンバーガーメニュー）の構築
- 背景動画（`<video>`）の全幅固定配置
- CSSでのグラデーション透過・ホバーアニメーション演出
- CSS（疑似要素・`ol`/`dl`タグ）を使ったフロー図の作成
- `outline` プロパティを活用した枠線ホバー時のレイアウト崩れ防止
- jQueryによるスクロール検知（トップへ戻るボタンの表示・非表示・スムーススクロール）
- Git / GitHubによるバージョン管理

## 使用技術

- HTML5
- CSS3
- JavaScript（jQuery）
- Git
- GitHub
